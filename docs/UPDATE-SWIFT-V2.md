# 2026-09-14：Swift 离线研究版 v2

当前唯一有效配置为 thesis-swift-offline-v2.0.0。本文件及 [配置 README](../sysmon/README.md) 取代此前更新说明中的事件策略。旧说明保留为历史记录。

## 本次更改

- 从固定 SwiftOnSecurity XML 重新构建；不再叠加 Sysmon Modular。
- ID 1/5/11/26 全范围；ID 2 保留原筛选；ID 3/22 关闭。
- ID 7/9/10 保留 Swift 的关闭状态；其他活动规则语义不变。
- 禁用删除归档、剪贴板采集、额外进程篡改检测、文件阻止和 ID 29 扩展。
- 六项核心自检代替旧的八项自检，不再要求任意测试注册表键必须产生事件。
- host、guest、preprocess 代码保持不变，保留已有接收端进度写入容错。
- 更新主手册的快照名和批次目录，防止旧成功记录导致新配置任务被跳过。

## 用户需要部署什么

已有接收程序的用户只需复制新 XML 和可选的 tools/Test-ResearchTelemetry.ps1。安装/更新命令、指纹、事件取舍、验证步骤和研究限制均见 [配置 README](../sysmon/README.md)。无需运行 Python 生成器后再安装。

正常和恶意数据必须使用同一个配置版本。文件系统中的配置哈希不等于已加载配置；还需验证 Sysmon 更新返回成功及实际配置。不得把旧批次与新批次无标识混合。

本包尚未在用户虚拟机上安装，也没有启动样本、修改网络、恢复或创建快照。
