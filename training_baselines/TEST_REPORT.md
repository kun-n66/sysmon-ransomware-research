## 验证环境与范围

- Windows 本地 CPU；TensorFlow 2.20.0、Keras 3.15.1、NumPy 2.5.3、scikit-learn 1.7.2。
- 已核对真实主实验数据及其固定划分：512 次候选采集，训练/验证/测试分别为 355/73/84 次，对应 21,240/4,364/5,726 个 system 片段。
- 两个架构的完整训练流程使用已有小规模数据做一轮训练验证：53 次采集、1,326 个 `[64,148]` 片段。测试夹具只将最大 epoch 改为 1，不修改交付 Notebook 的默认配置。
- 逐个执行 Notebook 的全部代码单元，包括训练、验证集阈值选择、测试结果保存、绘图、模型重载和结果 ZIP。仅模拟 Colab 的 Drive 挂载及浏览器下载接口。

这是工程验证，不是新一轮正式论文实验，也不是已在 Colab GPU 上完成的验证。正式使用时，Notebook 继承主实验的 `[32,148]` 输入及最多 40 epoch 预算。短程测试分数不作为研究结论。
